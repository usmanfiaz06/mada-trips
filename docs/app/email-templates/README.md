# Supabase email templates

Paste each file into Supabase → Authentication → Emails → Templates. All of them show the 6-digit code (`{{ .Token }}`), never a link.

| Supabase template | File | Subject |
|---|---|---|
| Confirm sign up | `confirm-signup.html` | Welcome to Mada Trips · أهلًا بك في مادا |
| Magic link or OTP | `magic-link.html` | Your Mada Trips code · رمزك في مادا |
| Change email address | `change-email.html` | Confirm your new email · أكّد بريدك الجديد |
| Reset password | `reset-password.html` | Reset your Mada Trips password · إعادة تعيين كلمة المرور |

# Prototype source

The clickable prototype of eight screens, published as a design canvas at
https://claude.ai/artifact/RJENJXQ4wAqdMZvvQ2ssy5 (private until shared from its Share menu).

These files are the canvas's source, kept here for reference.

- **Images** are referenced as `/_blob/…` URLs. Those only resolve inside the published canvas.
- **People** are shown as initials. Real agent and family photos come later.
- **Haptics** use `navigator.vibrate`, which only works on Android browsers. The real app uses native haptic patterns ([EXPERIENCE.md §4.6](../EXPERIENCE.md)).
